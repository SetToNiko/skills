# Agent skills

A copy of each skill that was installed for Claude Code on 2026-11-26. One folder for each skill. Each folder has a `SKILL.md`.

This repository (`SetToNiko/skills`) tracks the originals and `mentor`. `asd-ste100` is a git submodule of its upstream repository (`danyuchn/asd-ste100-skill`). The snapshots stay in `~/agent-skills` only: the `.gitignore` excludes them.

Two kinds of folders:
- **original:** this folder is the installed skill. `~/.claude/skills/<name>` is a link to it (and `~/.agents/skills/<name>` for the skills of the `skills` tool). A change here is live at once.
- **snapshot:** a copy. claude.ai or the plugin manager installs and updates these skills in its own folders, so a link would break on the next update. A change here does not change the installed skill.
